An AI-powered text tone conversion app built using Python, Flask, and Ollama.

This project takes normal text input and rewrites it in different tones such as:
- Professional
- Friendly
- Polite
- Aggressive
- Motivational
- Casual

Currently, the backend API is working locally using a local LLM through Ollama

## Tech Stack
- Python
- Flask
- Ollama
- REST API
- JSON

## Features Completed So Far

- Flask backend setup
- REST API endpoint created
- JSON request/response handling
- AI integration using Ollama
- Dynamic tone conversion
- Local AI processing without paid APIs
- Curl testing completed
